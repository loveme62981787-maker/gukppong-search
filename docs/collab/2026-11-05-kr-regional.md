# 한국어 지역 해시태그 수집 (일본체험·대만체험 추가)

요청: #후쿠오카 #도쿄 #단수이 #타이베이 같은 한국어 지역 해시태그·지역명으로 한국어 제작자의 현지 여행·체험 원본을 찾아 일본체험/대만체험에 추가한다.

## 규칙
- 근거는 제목에서 확인되는 것만 쓴다: 한국어 지역명(해시태그 포함) + 한국어 체험 단어 + 롱폼(181초 이상, 길이 불명은 제외).
- 뉴스·재편집(반응·요약·모음·하이라이트 등)·쇼츠·국내 지명 혼합·일본과 대만 혼합 제목은 제외한다.
- **제목이 한글이라는 이유로 제작자 국적을 확정하지 않는다.** 저장값은 `ko_title`(한국어 제목 근거)이고, 화면은 "추정"으로만 표시한다. 채널 국적도 확인하지 않았다고 명시한다.
- `단수이`는 '단수(물 공급 중단)' 오탐이 많아, 단수 관련 단어가 있으면 제외하고 대만 근거 단어나 여행 단어가 있을 때만 인정한다.
- 화면 교정은 좁게: 수집기가 통과시킨 영상(`kr_regional`)만, 소재 나라가 같고 제목이 한글일 때만 '현지 편집(local)' 추정 대신 '원본(foreign)'으로 본다. 개인 보정·공통 검토(수동 분류)가 항상 먼저다. 기존 일본 한국어 제목 영상은 그대로다.
- 같은 영상 ID가 기존 데이터에 있어도 `absorb`가 `kr_*` 근거만 덧붙이고 기존 필드·목록은 바꾸지 않는다.
- 검색이 실패하면 이전 저장분(`kr_regional_store.json`)을 그대로 두고 새 결과만 합친다.

## 구성
- `kr_regional_watch.py`(일본 11·대만 8개 지역, 지역마다 해시태그+조합 검색, 병렬 3) → `kr_regional_store.json`, `web/kr_regional.js`
- 기존 아침·수동 실행에서 `taiwan_watch.py`가 한국어 지역 수집기를 호출하고 생성 파일 두 개를 데이터 커밋에 포함한다.
- `license_watch.py`: 새 영상 ID도 라이선스 확인 대상에 포함
- 테스트: `tests/test_kr_regional.py`, `tests/test_kr_regional.mjs`

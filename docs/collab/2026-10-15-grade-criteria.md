# 협업 기록: 소재 등급(S/A/B) 기준과 데이터 계약 (2026-10-15)

참여: Claude Code(점수·등급·화면), Codex(수집·병합·테스트). 토론 2라운드, 읽기 전용 호출. 사용자의 정의: "국뽕 채널 소재로 가장 좋은 영상 = 사건·조회수·이슈가 될 만한 소재".
※ 제목·조회수 기준의 잠정 판단이며 영상 내용과 출처를 직접 검증한 결과가 아니다.

## 합의
1. **적합성 관문이 먼저, 점수는 그다음.** 대상국(한국/일본) → 반응 주체(외국인이 체험·반응) → 구체적 체험 또는 사건. 관문을 통과하지 못하면 점수가 높아도 등급 없음. 수동 승격도 관문과 공식 기관 상한을 우회하지 않는다.
2. **유형 2가지**: 체험형(외국인의 상시 체험·반응, 외국인 체험·반응이 근거) / 사건형(한국·일본 관련 구체적 사건·성과, 확인 가능한 근거가 근거).
3. **점수 보정**: 조회수 점수는 1천만까지 확대, 조회수·비율 이중 보상 완화, 구독자 결측은 1로 대체하지 않고(비율 점수 없음) 1천 미만은 분모를 1천으로 보정(※ 초안의 '1천 미만 제외'를 피어 세션 의견과 Codex 교차 검토로 수정), 이슈 단어에서 그룹명(BTS 등) 제거, '세계 최초'/'최초' 중복 계산 제거, 정부·공식 기관 채널은 최대 A.

### 교차 검토 반영 (구현 후, Codex 검토)
- 외국인 판정: 국적 단어는 사람 단어와 붙을 때만 인정, 비한글 채널 기반 경로 삭제(한국인이 운영하는 영어 채널 오탐 방지)
- 팬 리액션 제외 범위를 그룹명 전체로 확대, 소재가 제3국인 영상 제외, 한국인이 외국에 가는 역방향 보강
- '수상'(수상택시 등 다의어)을 사건 단어에서 제거, 증가 속도 가점은 0~5로 제한하고 이력 형식 검증 강화

### 피어 세션 교차 검토 반영 (main 7c290b7 기준)
- **롱폼 관문**: 길이가 확인된 181초 이상만 등급을 준다. 쇼츠(180초 이하)는 등급 제외, 길이를 모르는 영상은 '길이 확인 필요'로 따로 모은다(수집기가 길이를 채우면 자동 판정). 사용자의 롱폼 위주 요청 반영.
- **한글 비율 버그**: `hangulRatio` 가 `\W` 로 한글까지 지워 항상 0이었음 → 글자(`\p{L}`)만 남기고 계산하도록 수정.
- **'급상승' 표기 삭제**: 이 비율은 평생 조회수 ÷ 구독자라 증가 속도가 아니므로 '구독자 대비 높음'으로 표기. 증가 속도는 조회수 이력이 쌓인 영상만 점수 가점으로 쓴다.
- **미해결(Codex 담당 파일)**: 조회수 파싱 실패가 0으로 기록되는 문제(`discover.search` 의 `or 0`), `merge_history` 가 잘못된 시각·행에서 예외를 내는 문제. 별도 브랜치에서 수정·테스트 후 제안받아 검토·병합한다.
- **중복 구현 정리**: 조회수 이력은 `c3058d5`/`c33107b` 로 이미 병합됨. 피어 세션의 별도 구현(`1f8dabb`)은 중복 병합하지 않고, 필요한 차이만 새 브랜치로 제안받는다.
4. **S의 개수는 결과**: '상위 몇 %'가 아니라 관문 + 점수 기준선 + 수동 검수로 정한다.
5. **역방향·단순 팬 반응 제외**: 한국인이 외국 것을 보고 놀라는 영상, 중국이 소재인 일본 반응 영상, 아이돌끼리의 BTS 리액션 등.

- **Claude**: `web/index.html`(관문·유형·점수·등급·UI·근거 표시), `web/curation.js`(수동 검수 ID 목록)
- **Codex**: `discover.py`, `discover.ini`, `build_site.py`, `tests/` — 영상 항목에 `observed_at`(시간대 포함 ISO), `subs_checked_at`, `views_history`([[관측시각, 조회수], ...] 최대 12개) 추가

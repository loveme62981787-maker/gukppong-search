# 내 채점 독립 탭

사용자 요청에 따라 국뽕 점수 다음 네 번째 내 채점 탭을 추가했다. 잠정 등급과 FM 채점 필터가 교차 적용되는 혼동을 해소한다.

- Claude 검토 요청은 사용 한도(429)로 실패했다. 담당 index.html은 수정하지 않고 web/my_scores.js를 auto_scores.js 내보내기에 포함했다.
- 영상 탭의 FM 필터 줄을 숨기고 선택을 비운다. 잠정 등급은 영상 탭에 유지한다.
- 새 탭의 목록·FM 등급·검색·정렬은 독립 상태다. 사용 완료·메모는 기존 ID 기반 저장을 공유한다.
- 목록은 합집합이며 선택 목록 기준으로 채점 완료·A/B/C·보류·미채점 수를 보여 준다. 기본은 채점 완료이며 C는 마지막에 정렬한다. 미채점 대량 목록은 48개씩 더 보기로 표시한다.
- Python 31개와 기존 Node 12개 통과. 브라우저에서 잠정 B 선택 후 새 탭 전환 시 결과 독립성, 텔레그램 양국 선택 시 완료 2개·미채점 249개를 확인했다.

자동 채점에서 export를 실행하면 새 탭 코드도 함께 유지된다. 공개 원문·연락처 추가는 없다.

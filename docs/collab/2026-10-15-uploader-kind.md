# 협업 기록: 영상 출처 분류 — 외국인 원본 / 현지 편집·소개 / 기관·방송 / 미확인 (2026-10-15)

참여: Claude Code(`web/index.html`, `web/curation.js` 담당), Codex(읽기 전용 검토). 토론 2라운드 + 구현 후 검토. 데이터 계약·Codex 담당 파일 변경 없음.

## 요청
"외국인이 촬영한 영상과, 내 채널과 비슷한 한국 국뽕 채널이 섞여 나온다. 확실하게 분리해 달라." (스크린샷: 외국인 개인 채널 MassiveAsif·Nicole García·Mansi in korea·Tidy with SPARK와 국내 국뽕 채널 한국반응포착·코리아핫TV 등이 한 화면에 섞임)

## 기존 문제 (실제 데이터)
- 기존 `_up`: 채널명에 한글이 있거나 제목 한글 비율 ≥ 0.3 이거나 벤치마킹 목록 채널이면 '국내', 그 외 전부 '외국인'. 필터는 접힌 '상세 조건' 안에 있었고 카드에 구분 표시가 없었다.
- 국내로 분류된 1,064개 중 291개는 제목이 외국어인데 **채널명이 한글**이라는 이유로 국내가 됨(영국남자 Korean Englishman 29, 김치귀신 마이 등 외국인 운영 채널 포함).
- 외국인으로 분류된 2,434개에는 Arirang News·KOREA NOW·Koreanet·VisitSeoul TV 같은 **기관·방송**의 영어 영상이 섞임.

## 합의
1. **분류 4칸**(소재 출처 기준): 🌏 외국인 원본 / 🧭 현지 편집·소개(내 채널과 비슷한 현지 운영 국뽕 채널이 편집·번역한 소개 영상) / 🏛 기관·방송 / ❓ 미확인. '외국인'은 대상국(한국·일본) 기준.
2. **자동 판정은 추정**이며 확정이 아니다. 근거가 부족하면 미확인. 우선순위: 개인 보정(영상) > 개인 보정(채널) > 공통 검토(영상) > 공통 검토(채널) > 자동 추정.
3. **기관·방송은 채널 ID 완전 일치만** 사용(이름 부분 일치는 `Alex Gonzaga Official`·`bibi.bea.official`·`불꽃주식TV` 같은 오분류가 많아 폐기). 근거와 검토일을 `web/curation.js`에 남긴다.
4. 수동 보정은 **채널 ID 기준**. 개인 보정(이 브라우저에만 저장)과 공통 기본값(`curation.js`, 근거·검토일 포함)을 분리하고 영상 단위 예외를 허용한다. 내보내기·초기화 제공.
5. **개인 보정은 소재 분류만 바꾼다.** 공식 기관 등급 상한(최대 A)은 별개 규칙이며 해제되지 않는다(등급 계산은 출처 분류와 독립).
6. 한국어 제목은 '현지 편집·소개'(외국인이 한국어로 운영하는 채널은 공통 목록으로 보정). 일본어 제목 + 일본 주제는 현지 편집·소개, 일본어 제목 + 한국 주제는 미확인. 채널명이 한글이어도 제목이 외국어면 미확인(운영 주체를 알 수 없음).
7. 화면: '출처' 선택을 자주 쓰는 줄 맨 앞에 크게 두고, 카드에 색 띠와 배지(툴팁에 근거: 추정/수동/공통 검토)를 항상 표시, 마지막 선택은 브라우저에 기억. 카드의 접힌 '분류 바꾸기'(기본 채널 단위, '이 영상만' 체크 시 영상 단위). 여행 분류(`_krTrip/_jpTrip`)는 외국인 원본일 때만 참.

## 이견 (기록)
- **쟁점**: 제목·채널명이 외국어이고 한글 채널명이 아니며 벤치마킹 목록에도 없는 영상을 '외국인 원본'으로 볼 것인가.
- **Codex**: 국적·원본성의 근거가 아니므로 기본은 미확인.
- **Claude**: 그러면 외국인 원본 칸이 사실상 비어 사용자의 '확실한 분리' 목적을 못 이룬다. 그래서 **근거가 있는 경우만 '외국인 원본(추정)'**으로 한다 — (a) 한국어·일본어·영어가 아닌 언어(스페인어·러시아어 등)로 만든 영상, 또는 (b) 영어 제목에 일인칭·체험 표현이 있고 한글 채널명·기관·벤치마킹 채널이 아님. 근거가 없으면 미확인.
- 결정: Claude 안 채택(사용자 목적 우선), '추정'임을 배지 툴팁·칩 설명에 명시. 구현 후 Codex가 실제 개수와 오분류 표본을 보고 다시 의견을 낸다.

## Codex 구현 검토 결과 → 수정 (6건)
1. **저장값 검증 없음(높음)**: 변조된 보정 문자열이 화면 코드에 들어갈 수 있었고 가져오기 검사가 `in` 이라 `"toString"` 같은 값을 허용 → 허용된 kind 값만 받는 `cleanMap`(프로토타입 없는 객체, `__proto__` 제외, 배열 거부)과 `own()` 으로 교체. 변조된 저장값(HTML 문자열·배열·위험한 키)을 심고 새로고침해도 정상 로드, 값은 걸러짐.
2. **선택 기억값 오류로 화면 초기화 중단(높음)** → 배열이 아니거나 허용되지 않는 값은 무시.
3. **비영어 판정이 언어 판정이 아님(중간)**: 채널명 악센트 한 글자, `×`·`÷`, 한자 제목도 통과 → 제목만 보고, 악센트 라틴 문자 2자 이상 또는 그리스·키릴·아랍·데바나가리·태국 문자 2자 이상일 때만. `日本旅行 × Seoul`·`Seoul ÷ Busan`·채널명 악센트만 있는 경우는 미확인.
4. **일인칭 근거가 느슨함(중간)**: `react`·`tourist`·`living`·`moved` 는 제3자도 쓰는 단어 → 근거에서 제거. 근거는 my/our/we/I/me, first time/day, vlog, 또는 국적+사람 표현(Indian student)만. `Koreans react to tourists in Seoul`·`Cost of living in Seoul` 은 미확인.
5. **보정 후 여행 칩 개수 낡음(중간)** → 출처 개수와 함께 여행 칩 개수도 갱신(보정으로 261→259, 칩 = 실제).
6. **기관 등급 상한이 이름 정규식(후속)** → 공통 검토로 확인한 기관 채널 ID 목록(`INST_IDS`) 기준으로 교체. Arirang News 같은 채널이 빠지던 문제와 `Alex Gonzaga Official` 같은 개인 채널이 잡히던 과포함이 함께 해소. 개인 분류 보정은 등급 계산과 무관(`scoreAll()` 에 `_kind` 참조 없음).
- 수정 후: 스크린샷 사례 8건 일치, 외국인 원본 1,019 / 현지 편집·소개 813 / 기관·방송 73 / 미확인 1,593, 등급 S10/A60/B143 불변, 불변 조건(제외·강등·기관 S·관문·후킹·쇼츠·여행) 전부 0.
- **이견에 대한 Codex의 추가 의견**: 위 3·4 수정으로 Claude 안('근거 있는 추정')이 합의의 '근거 있는 추정' 범위로 좁혀짐. 외국인 원본이 구현 직후 1,274 → 1,019 로 줄었고, 나머지는 미확인으로 남아 사용자가 카드의 '분류 바꾸기'나 공통 목록으로 확정한다.

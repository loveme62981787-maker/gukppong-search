# 비대만인 대만 현지 체험 목록 검토

135개 대만 주제 영상의 공개 영상 설명(132개 응답, 3개 실패) 및 중복을 합친 채널 소개 114개(112개 응답)를 확인했다. 현지 체험 및 비대만인 출연자 근거가 분명한 39개만 대만체험 목록에 포함한다. 기존 후보 24개 중 5개 유지, 34개 신규 편입, 기존 19개는 확인 보류로 전체 목록에 보존한다. 다른 목록 소속, 영상 ID, 점수는 유지한다.

언어·이름·외모만으로 국적을 추정하지 않는다. 비대만인 자기소개/영상 설명상의 출연자 소개를 사용한다. 대만인 동행자가 있어도 비대만인 체험자가 확인되면 포함한다. 대만 밖 여행/음식 체험, 정보 편집물, 출연자 불명은 편입하지 않는다. 영상 전문 시청이나 FM 채점 완료를 뜻하지 않는다.

공개 결과는 선별 ID와 안내문만 반영한다. 원문 설명·채널 소개·개별 판정 기록은 저장소 외부 telegram-score-private에 보관한다. 기존 후보 데이터는 삭제하지 않는다. 자동 검색 결과가 검토 없이 편입되지 않도록 명시 ID 허용 목록을 사용한다.

Codex 담당 별도 모듈만 변경. index.html 수정 없음. Python 54개, Node 13개 통과. 브라우저 전체 8189개 보존, 대만체험 39개와 나라 대만 39개 일치 확인.

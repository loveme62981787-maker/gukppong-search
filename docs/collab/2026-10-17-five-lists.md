# 협업 기록: 영상 목록 5개 재편성 (2026-10-17)

참여: Claude Code(`web/index.html` 담당), Codex(읽기 전용 검토 2라운드).

## 요청
섞인 '전체' 목록을 없애고 정확히 5개 목록으로 나눈다: 📓 노션 수집 목록(기존 그대로 + 영상에 표시) / 🇰🇷 한국 체험(한국 사람이 아닌 외국인이 한국을 여행·체험·경험·출연) / 🇯🇵 일본 체험(같은 방식, 일본) / 🧭 국뽕채널·한국 버전(내 채널과 비슷한 채널) / 🎌 국뽕채널·일본 버전.

## 합의한 규칙 (Claude + Codex)
- 한 영상이 여러 목록에 동시에 속할 수 있다(체험 목록은 '누가 등장해 무엇을 경험하나', 국뽕채널은 '누가 어떤 방식으로 만들었나'). 노션은 내용 분류와 독립된 출처 목록이다.
- 한국 체험 = 외국인 원본(추정) + 한국 소재, 일본 체험 = 외국인 원본(추정) + 일본 소재. 한일 혼합(both)은 제목에 해당 나라의 장소 신호가 있을 때만 그 나라 체험에 넣는다(두 나라 신호가 모두 있으면 두 목록).
- 국뽕채널·한국 = 현지 국뽕 채널(한국어 제목 + 한국 소재) + 사용자가 알려 준 별도 레퍼런스 채널 전체(사용자 지정 채널 기준). 국뽕채널·일본 = 일본어 제목 + 일본 소재의 현지 채널.
- 근거가 부족한 영상(미확인·기관·방송·대만·한일 혼합 신호 없음)은 어느 목록에도 억지로 넣지 않고 '분류 보류'에 둔다. 노션 영상이라도 내용 목록이 없으면 보류에도 속한다.
- 모든 소속은 제목·채널 정보로 한 '추정'이며 영상 내용(출연자 국적)을 보고 확인한 것이 아니다. 카드에 목록별 태그와 근거를 표시한다. 사람이 '출처 유형 바꾸기'로 외국인 원본/현지 채널을 고르면 해당 목록으로 옮겨진다.

## 이견과 결정
- Codex: 체험 목록은 업로더·원본/편집과 무관하게 '출연자'로 판정해야 한다. Claude: 출연자 국적을 데이터로 알 수 없으므로 현재 단계에서는 외국인 원본 추정을 대리 신호로 쓰고 전부 '추정'으로 표시한다 → Codex 동의(안내 문구를 '출처 유형 보정'으로 정확히 쓸 것을 조건으로).
- Codex: 레퍼런스·기관을 일괄 배제하면 유효한 영상이 빠진다. Claude: 사용자 지정 한국 채널 8개는 국뽕채널·한국에 전부 넣고 기관·방송은 보류 → Codex 동의.

## Codex 구현 검토 결과 → 수정
1. both 영상이 체험 목록에 들어갈 수 없던 문제 → 제목의 나라별 장소 신호로 독립 판정. 2. 노션만 있는 미분류 영상이 보류에서 빠지던 문제 → 보류는 내용 목록 기준(`_hold`). 3. 목록을 옮겨도 지방·노션 필터가 남던 문제 → 목록 전환 시 해제. 4. 안내 문구를 '출처 유형 바꾸기'로 정정. 5. 국뽕채널 태그에도 (추정) 표시, 레퍼런스는 '사용자 지정 채널 기준'. 6. 대만 등을 '한일'로 표시하던 것 → '기타'. 7. 하위 칩 전체 개수 기준 정정(노션). 8. 레퍼런스 툴팁 정정.
미해결(알려진 한계): 한국인 출연자의 일본 체험 같은 '출연자' 기반 판정과 영상 내용 확인은 아직 못 함, 일본어 제목+한국 소재는 보류, 칩의 소속 개수는 숨김·사용 완료·숏폼을 포함한 총수라 결과 수와 다를 수 있음.

## 추가 작업 (2026-10-17 오후): 꼭지 채우기와 채널 위치 근거
- 영상이 8개 미만인 꼭지만 검색어 변형 4개 × 정렬 3개로 더 깊게 수집(`global_topics_watch.py --fill`, 한국 +303, 일본 +472). 검색 순위만으로 꼭지를 붙이지 않음.
- 새 영상은 대부분 '외국인 원본' 근거가 부족해 보류로 들어가 목록이 거의 안 늘었다 → 채널 정보 페이지의 위치(국가)를 읽어(`channel_country_watch.py`, 4,109개 채널 중 2,988개 국가 확인) 한국·일본이 아닌 해외 위치 + 제목에 해당 나라 표현이 있으면 외국인 영상으로 추정. 한국·일본 위치는 판정에 쓰지 않음(현지에 사는 외국인 채널도 같은 값).
- Codex 정확도 검토: 표본에서 퀴즈·작품 요약·안내서·다큐 해설이 체험으로 분류됨을 지적. 해외 위치 단독으로 외국인 확정 금지, 비체험 신호 제외 제안 → 비체험 제목(quiz·recap·guide·top N·how to·explained 등)은 직접 체험 신호(I·my·first time·vlog·trip 등)가 없으면 체험 목록에서 제외(`NONEXP_RE`/`EXPSIG_RE`), 보류로 이동.
- 이견: Codex는 정밀도를 32~58%(표본 19개, 매우 엄격한 해석)로 봄. Claude는 표본 50개를 눈으로 본 결과 약 85~90%로 봄. 두 추정 모두 영상 내용을 확인한 것이 아니며 표본이 작아 신뢰구간이 아님. 영상별 확인(사람 검수)이 필요하다는 점에 합의.

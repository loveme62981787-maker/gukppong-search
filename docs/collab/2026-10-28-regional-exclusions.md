# 소재별 대표 도시 제외 필터 (2026-10-28)

사용자 요청으로 `web/index.html`(Claude 담당)에 화면 필터를 추가했다. 영상 데이터·점수·분류는 바꾸지 않는다.

## 칩
- 🇰🇷 한국 소재 탭: `🚫 서울·부산·제주 제외`
- 🇯🇵 일본 소재 탭: `🚫 도쿄 제외`
- 🇹🇼 대만 소재 탭(새로 추가): `🚫 타이베이 제외`

## 판정 (`rxMatch`, 제목 기준 추정)
모두 만족해야 통과한다.
1. 소재(`_subj`)가 해당 나라
2. 제목에 다른 지역 이름이 명시 (한국은 기존 `REGIONS`/`regionsOf`의 제주 외 지역, 일본·대만은 영문·한글·한자/가나 지명 목록)
3. 제외 도시 언급 없음 (한국: 기존 `SEOUL_BUSAN_RE` + 제주 전역 / 일본: 도쿄·주요 구 / 대만: 타이베이·시먼딩·스린 등)
4. 다른 나라 지명 없음 (혼합 여정 제외)

- 위치 미확인 영상은 지방으로 추정하지 않는다(통과하지 않음).
- 대만의 신베이(New Taipei·新北)는 타이베이와 별개 지역이라 제외 판정 전에 지우고, 지역 근거로는 인정한다.
- 한글 '나라'처럼 일반 단어와 겹치는 이름은 쓰지 않는다(일본 나라는 `nara` 영문·奈良·나라현만).

## 동작
- 선택은 `rxSel` 하나를 세 칩이 나눠 쓴다. 나라가 다른 칩끼리는 OR, 다른 필터와는 AND.
- 선택한 필터 요약(×로 해제)·탭 배지·`전체 초기화`는 기존 `MULTIS` 경로를 그대로 쓴다.
- 칩 숫자는 `web/list_counts.js`의 선택 목록 기준 집계(`rxkr/rxjp/rxtw` 그룹)로 갱신한다. `list_counts.js`는 `rxMatch`를 전역으로 참조한다.
- `taiwan_hidden.js`가 나중에 `_subj`를 바꿔도 판정은 필터 시점에 하므로 영향이 없다.

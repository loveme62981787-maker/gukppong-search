# 협업 기록: 🎯 국뽕 점수(스크립트 채점) 레이어 추가 (2026-10-20)

참여: Claude Code(`web/index.html`·점수 기준·채점 기록). Codex 검토는 아직 받지 않았다 → 아래 '검토 요청'.

## 요청
사용자가 Claude 스킬(`gukppong-score-kr` / `gukppong-score-jp`)로 스크립트 40여 개를 채점해 왔고, 이 점수 기준을 사이트에 접목해 달라고 했다. 선택: 기존 목록·필터·검수 기능은 그대로 두고 **점수 레이어를 얹는다** + 스크립트를 붙여넣으면 사이트에서 예비 점수를 내는 **간이 채점기(참고용)**를 넣는다. 푸시 전에 사용자에게 먼저 묻는다.

## 두 점수는 별개다
| | 🏆 등급 (기존) | 🎯 국뽕 점수 (신규) |
|---|---|---|
| 근거 | 제목·조회수·후킹어·최신성 (`scoreAll`) | 스크립트(자막) 전문을 읽고 사람이 채점 |
| 범위 | 수집한 모든 영상 | 채점한 영상만 (현재 44개 기록, 점수 40개 + 보류 4개) |
| 의미 | 소재 검토 우선순위(조회수·화제성) | 국뽕 소재로 얼마나 쓸 만한가 (6항목 100점) |
| 색 | 노랑/파랑/회색 | 노랑(S)/초록(A)/보라(B)/회색(C)/주황(보류) |
두 점수는 서로 계산에 쓰이지 않는다. 카드에 둘이 함께 보일 수 있다.

## 점수 기준 (web/scorer.js 의 RUBRIC·GRADES, 사이트 '점수 기준' 화면이 그대로 읽음)
포인트 밀도 25 · 반응 강도 20 · 반전·낙차 20 · 소재 희소성 15 · 썸네일화 10 · 호의 일관성 10 = 100. 등급 S 85+ · A 70~84 · B 55~69 · C 54 이하. 국뽕 포인트는 '외국인이 구체적 장면을 직접 겪고 반응을 보인 것'이 1개, 반응이 약하면 0.5개. 갈래는 한국 12 / 일본 12.
원칙: 스크립트에 있는 것만 센다 · 광고·협찬 구간과 비하·민감 발언은 점수와 별개로 '확인·주의'에 적는다 · 대사가 거의 없으면 점수를 내지 않고 '보류' · 타임스탬프가 없으면 분량을 가정하고 가정했다고 표시한다.

## 구현
- `web/scorer.js`: 기준 데이터 + `estimate(text, {ver, minutes})` 간이 채점기. 감탄어·갈래 키워드·반전 표현·부정어로 센 규칙 기반 값이다.
- `web/scores.js`: 채점 기록(`window.SCORES.items`). 생성 파일이 아니라 손으로 옮긴 파일이다. 항목 형식은 파일 맨 위 주석. `id` 가 있으면 같은 영상 카드에 배지·상세가 붙는다.
- `web/index.html`: 🎯 국뽕 점수 화면(📏 기준 / 🏆 기록 / 🧮 간이 채점기), 영상 카드의 점수 배지와 '점수 자세히', 필터 '🎯 내 채점'(채점됨·A 이상·B·C·보류 × 한국판·일본판), 정렬 '🎯 내 채점 점수순'. 기존 `V`·필터·등급 계산은 건드리지 않고 `v._sc` 한 필드만 붙인다.
- `.github/workflows/update.yml`: push 트리거 경로에 `web/scorer.js`, `web/scores.js` 추가 (점수만 고쳐도 바로 배포).
- `tests/test_scorer.mjs`: `node --test tests/test_scorer.mjs` (9개: 기준 합계 100, 범위, 부정어 감점, 분량 우선순위, 빈 입력·음악뿐인 입력, 광고·민감·욕설 경고, 일본 갈래, 비영어 경고).

## 알려진 한계 (화면에도 표시함)
- 간이 채점기는 사람이 매긴 점수와 ±10점 이상 다를 수 있다. 영어 위주이며, 반전·희소성은 특히 거칠다. 사람이 매긴 사례 40개로 보정하지 못했다(스크립트 원문을 파일로 보관하지 않음). 그래서 오차를 ±12점으로 가정해 표시한다.
- 채점 기록 44개 중 영상 ID 가 있는 것은 10개뿐이라 메인 카드에 붙는 배지는 적다(그중 사이트 수집 데이터에 있는 8개). ID 를 알게 되면 `scores.js` 에 `id` 만 채우면 된다.
- 점수는 소재 검토 우선순위이지 조회수·클릭률 예측이 아니다.

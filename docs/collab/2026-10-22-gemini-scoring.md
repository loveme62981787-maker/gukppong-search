# Gemini 1차 채점과 Codex 검증

사용자 요청: Gemini를 기본 채점자로 사용하고 Codex가 검증한 결과만 게시한다. 애매한 영상만 Claude에 확인하며 DeepSeek은 제외한다.

- `score_alerts.py score`는 기본 Gemini(Antigravity CLI)를 호출한다. `GEMINI_CLI_PATH`로 실행 파일을 지정할 수 있다.
- 모델 응답만으로 게시하지 않는다. 원문·시각·점수 범위 검사를 통과해도 비공개 검토 결과로 남긴다.
- Codex는 인용 맥락, 등장인물, 반복 장면, 긍정·부정 반응 및 FM 적용을 검토한다. 검증한 JSON만 `--review-file`로 승인한다.
- 55/70/85점 경계에서 2점 이내이거나 보류인 결과는 Claude 검토 권고를 표시한다. 의미상 애매한 결과도 검토한다. Claude 호출 실패 시 게시하지 않고 보류한다. 자동 재호출하지 않는다.
- 기존 수동 채점과 이미 게시된 점수는 덮어쓰지 않는다. 출처는 `gemini_fm` 또는 `claude_fm`이며 DeepSeek 출처는 거부한다.
- 원문 자막·평가 근거는 저장소 밖에 보관한다. 공개 데이터에는 수치, 출처, 근거 해시와 고정 안내문만 추가한다.
- UI 담당 파일은 수정하지 않았다. 기존 별도 점수 데이터 연결을 사용한다. 점수 데이터 변경만으로도 배포되도록 workflow 경로에 `web/auto_scores.js`를 추가했다.

검증: Python 31개, Node 11개 통과. 한국 전통 결혼식 영상 61점은 전체 스페인어 자막을 검토하고 승인했다. 영상 속 역사 설명은 사실 검증 결과가 아니며 공개 데이터로 옮기지 않았다.

현재 작업은 로컬 실행 방식이다. 무인 반복 채점 스케줄은 아직 설정하지 않았다.

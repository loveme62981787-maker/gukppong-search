# 협업 기록: 글로벌 콘텐츠 일본 버전과 후보 데이터 합치기 (2026-10-16)

참여: Claude Code(`global_topics_jp_groups.py`, `global_topics_watch.py --jp`, `web/index.html`), Codex(읽기 전용 검토 + 별도 세션이 만든 주제 검색 후보 데이터).

## 요청
슬라이드의 12갈래·140꼭지로 전체 영상을 다시 분류하고, 외국인이 한국에서 해당 주제를 경험·체험한 영상을 찾아 올리고, 일본도 같은 체계로 해 달라.

## 결정 (사용자)
- 일본 버전은 Claude가 만든 것을 쓰고 Codex는 검증을 맡는다. 다른 세션(Codex)이 따로 만든 분류 체계는 쓰지 않고, 중복되는 영상·주제는 합친다.
- 합치는 방법: 같은 YouTube 영상 ID는 한 카드(출처 합집합), 갈래는 같은 12갈래 순서로 합집합, 꼭지는 이름이 같은 것만 합침. 다른 세션이 검색으로 모은 후보 313개(`data/topic_candidates.json` → `web/topic_candidates.js`)는 '체험 후보/관련 자료' 상태로 가져온다.

## Codex 검토 결과 → 반영
- 반영: 검색 순위만으로 꼭지를 붙이는 경로 제거(일본 버전 `PROVENANCE_TOP=0`), 한글 제목만으로 일본 영상이라 보지 않음, 일본어 강의 제외 추가, 넓은 규칙 좁힘(snow·clean·festival·curry·honest·can do·n'ex), `\b` 대신 파이썬·JS 같은 경계식(fax·noh), 프리쿠라 중복 정리, 한국·일본 주제 필터를 함께 고르면 OR(0건 방지).
- 미반영(알려진 한계): 영어 제목만으로 외국인 여부를 확정하지 못함(제목 기준 분류, 내용 미확인), `_subj` 가 '한일 혼합'인 영상(예: 한국인의 일본 체험)은 일본 갈래에서 빠질 수 있음, 일본 꼭지는 슬라이드 원본 명세가 없어 한국 꼭지를 일본에 맞게 옮긴 것(누락 여부 미확정).

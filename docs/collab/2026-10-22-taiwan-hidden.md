# 2026-10-22 대만 목록 · 잠정 등급 제거 · 숨김 관리

사용자 승인: 대만 알림을 기다리지 않고 영상 검색 후 게시, 기존 Claude 검수 영상 제외, 잠정 등급 표시 제거, 숨김 기능 개선.

- index.html은 변경하지 않았다. web/my_scores.js, web/taiwan_hidden.js를 auto_scores.js에 함께 내보낸다.
- 대만 24개 롱폼 후보: 유튜브 최신 검색 6개에서 선별, watch 페이지 게시일 및 채널 구독자 확인. 제목·채널에 근거한 후보이며 전문 검수·채점 완료로 표시하지 않는다. 기존 영상 ID와 병합해 중복 표시하지 않는다.
- data/taiwan_videos.json은 공개 메타데이터만 포함한다. 텔레그램 데이터로 가장하지 않는다. 현재 일회성 수집이며 별도 자동 검색 일정은 만들지 않았다.
- 잠정 등급 필터, 카드 등급 배지, 안내, 잠정 점수 정렬을 숨기고 저장된 등급 선택을 비운다. 내 채점의 검증된 점수는 보존한다.
- 상단 숨긴 영상 탭은 다른 필터에 관계없이 현재 브라우저에서 숨긴 영상만 보여주고 복원을 지원한다. 영구 삭제는 구현하지 않았다.
- Claude 비교 기준 3개는 코드에서도 재채점을 차단한다. 수동/자동 게시 점수는 기존 보존 규칙을 유지한다.
- Gemini 신규 2건 검토: 여행 안내 영상의 적용 범위, 번역 자막 해석에 의문이 있어 비공개 보류. Claude 한도 대기 기록에 포함했다. 검증 전 공개 점수는 추가하지 않았다.
- 검증: Python 33개, Node 12개 통과. 로컬 브라우저에서 대만 24건 조회, 숨기기→전용 목록→복원, 등급 숨김 확인.
- Claude는 알려진 사용 한도 해제 전이라 추가 호출하지 않았다. UI 담당 파일은 보존했다.
